Hexo创建新Post以及图片插入

创建Post：

1、在webstorm里面的命令行，将位置设为borm2.

2、输入命令行：hexo new 【hexo相关知识】（【为名称】），随后/Users/jiemeng/Desktop/other/bork2/source/_posts目录下会出现以【】为名字的md文件和一个文件夹。

3、可以再webstorm中找到md文件，并打开进行编辑

插入图片：

1、将图片直接粘贴至md文件中，会自动生成一个图片引用，同时/Users/jiemeng/Desktop/other/bork2/source/_posts目录下也会出现这个名字的图片


2、将这个图片放在同名文件夹中。
注意：上述需要安装 npm install hexo-asset-image –save插件，同时需要将hexo-asset-image版本降低至0.0.1,见链接https://alreadyright.github.io/2020/03/08/aboutHexo/ 同时保证_config.yml文件中的post_asset_folder: true
如果不行，可尝试直接使用来进行图片插入
